# Selection Auto Parts

Справочник автомобилей и мотоциклов, зависимые фильтры, избранные модели и
подбор запчастей по точной модификации и группе. Тестовый набор запчастей относится
к Ford Focus II седан (DB_) 1.6, 74 кВт, 04.2005–09.2012; для других автомобилей
отсутствие импортированных запчастей обозначается явно. Поиск по названию/номеру
пока отключён. Фотографии не импортируются.

Импортирован снимок 2/2018: 596 марок, 11 631 модельный ряд автомобилей и 1 543
мотоциклов, всего 75 843 модификации. Для указанного Focus импортированы 1 152
категории, 11 305 запчастей от 477 производителей и 26 571 связь с группами,
733 224 исходные OE-ссылки и 682 отношения замены. Размер облачной БД — около 454 МБ
без фотографий. Из дерева показываются доступные для модификации группы и их предки.

Архитектура повторяет `cooking-recipe`: pnpm workspace, `apps/web` (Next.js 16),
`apps/api` (Fastify), `packages/catalog-core` (Zod DTO и домен), `packages/db`
(Prisma 7 / PostgreSQL). На Vercel API обслуживается через Next.js `/api/v1/[...path]`;
самостоятельный сервер нужен только локально. Не требуется отдельный API-хостинг.

Node 24.20.0, pnpm 10.34.5. Все зависимости закреплены в lockfile.

```powershell
pnpm install --frozen-lockfile
# Создать .env из .env.example и настроить PostgreSQL
pnpm db:generate
pnpm db:migrate
pnpm dev
```

Сайт: localhost:3000; отдельный API: localhost:3002. Web получает локальный
DATABASE_URL из корневого `.env` через next.config.ts. Prisma CLI также читает `.env`.
В production используются только переменные Vercel.

```powershell
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm --filter web exec playwright install chromium
pnpm test:e2e
```

Серый глассморфизм, `/ru` (по умолчанию) и `/en`, сохранение темы cookie,
системная тема при первом посещении. Избранные ID моделей сохраняются в localStorage
`selection-auto-parts:favorite-models:v1`. Звёздочка находится справа от выбранной модели;
сохранённую модель можно восстановить из первой карточки. Недоступные модели можно удалить.
Избранное доступно только на том же origin в этом браузере, без синхронизации аккаунта.

Схема, миграции и транзакционный импорт находятся в `packages/db` и `scripts`.
Исходные ID и отношения не зависят от языка; RU/EN-метки хранятся отдельно в JSON.
Импорт проверяет формат, связи, контекст источника и модификацию Focus, сохраняет
хеш экспорта/версию и не создаёт вымышленные совместимости или кроссы.
Повторный импорт использует стабильные ключи и пропускает неизменившиеся строки.
Экспорты и секреты исключены из Git.

Процедура импорта: [docs/catalog-import.md](docs/catalog-import.md).
Публичные API: `/api/v1/vehicles/selection`, `/api/v1/vehicles/models`,
`/api/v1/parts/categories`, `/api/v1/parts/by-vehicle` (страницы по 20, максимум 50).
OE-ссылки и подтверждённые замены также выдаются по 20 записей; оставшиеся страницы
доступны через `/api/v1/parts/references` (`partId`, `kind=oe|crosses`, `page`,
`limit`, максимум 100). Порядок составных OE-ссылок сохраняется.
Модели запрашиваются по марке/виду транспорта или по максимум 100 избранным ID.
Измеренный максимум — 620 моделей у марки и 100 модификаций у модели; сервер
ограничивает выдачу 1000 моделями и 500 модификациями. Полный каталог не загружается в браузер.

Развёртывание и источник: [docs/deployment.md](docs/deployment.md),
[docs/tecdok-reconnaissance.md](docs/tecdok-reconnaissance.md).

Добавление языка: расширить `packages/catalog-core` locales, `src/i18n/routing.ts`,
добавить `apps/web/messages/<locale>/common.json`, включить словарь в тест полноты,
обновить canonical/hreflang и E2E маршруты, проверить перевод с редактором. Идентификаторы
моделей и localStorage не переводятся; компоненты получают текст через next-intl.
Переключатель обходит настроенный список locales; название следующего языка
показывается через Intl.DisplayNames на этом языке. Компонент не требуется менять
при расширении списка. Данные каталога используют цепочку locale → default locale → source EN.
