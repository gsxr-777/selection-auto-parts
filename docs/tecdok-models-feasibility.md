# Проверка чтения моделей TecDok — 09.10.2026

Это отчёт до разрешения на импорт. Позже в тот же день владелец подтвердил право
извлечения/публикации и поручил импорт; текущее состояние см. в `catalog-import.md`.

Техническое чтение автомобилей и мотоциклов подтверждено полным проходом через
публичные методы установленного `TMDVD.DAL.BDF`, версия 1.3.3.0. Reader сообщает
выпуск каталога `2/2018`; это снимок каталога, а не актуальная база автомобилей 2026 года.

ВМ: Windows 7 x86, .NET Framework 4, каталог
`C:\Program Files\TecAlliance\Catalogue`. Для диагностики собрана собственная
программа C# с системным csc.exe; выполнение через открытую desktop-сессию,
служебные результаты через `\\VBOXSVR\1`. Guestcontrol по-прежнему не используется.
Исходные DLL и BDF не редактировались. Загрузка библиотек настроена только в config
временной диагностической программы; настройки ОС и приложения каталога не менялись.

автомобильных марок. Авто/мото классифицировались наличием записей в

для каждой категории. Типы/модификации отличаются от модельных групп.

`enumerationErrors=0`, `labelErrors=0`, `emptyLabels=1`. Проход отмечен `COMPLETE`.

чистый результат проверки качества. Проверка штатного reader `IsSecurityOk` успешна,

## Реальные примеры

Автомобиль: ABARTH, source manufacturer ID 3854; `124 Spider (348_)`, source model
ID 36454; модификация `1.4`, source type ID 119512. В источнике: с 03.2016, дата
окончания отсутствует; 125 kW / 170 PS; технический объём 1368 cm³; код двигателя
55253268; Petrol; Convertible; Rear Wheel Drive. Отсутствие даты окончания в выпуске
2/2018 не означает, что автомобиль производится сегодня.

Мотоцикл: ADLY MOTORCYCLES, source manufacturer ID 4330; серия CAT, source model
ID 36688; Cat 50, source type ID 120374; с 01.2007, окончание не указано; 3 kW /
5 PS; технический объём 49 cm³. Это только пример записи, без утверждений о fitment.

Проверяемые локальные артефакты, исключённые из Git:

- `.cache/tecdok-probe/read-results.txt` — counters, два примера и пустая запись.
- `.cache/tecdok-probe/model-example.json` — пример автомобиля; сгенерирован из

## Ограничения и следующий этап

Массовый экспорт файлов с записями, importer, миграции и запись в PostgreSQL не
выполнялись. Собраны counters и небольшие диагностические примеры. Сайт продолжает
показывать пустой каталог. Условия лицензии/разрешённого использования установленного
выпуска и право публикации не получены; это остаётся условием перед импортом на сайт.

Для будущего импортера использовать офлайн-процесс рядом с ВМ, source ID, выпуск,
язык и страновой контекст. Язык и страна должны быть инициализированы до чтения
названий; без страны reader отдавал ArgumentNullException. Некоторые IModel имеют
оба флага IsPassengerCar/IsMotorbike: нельзя классифицировать модели по одному флагу.
Подготовить source-backed экспорт с проверкой FK make → model → type, missing labels,
дубликатов, количества и source hashes. Сначала малый sample, затем полный импорт.

Не переносить все строковые атрибуты в числовые колонки автоматически: например,
значение Number of valves в примере равно 4, но семантика «на цилиндр»/«всего» не
установлена. Сохранять исходные названия/значения и уточнять единицы перед нормализацией.
